This vault is a working prototype for the JangaFX priorities workflow.

Open the `vault/` folder in Obsidian and start with [[Start Here]].

What is included:

- a sample current cycle and a previous cycle
- mock priority notes across `backlog`, `todo`, `working`, `cancelled`, and `done`
- people notes with strengths, interests, and domains
- brief notes for team-facing communication
- templates for creating new notes consistently

Recommended first steps:

1. Read [[Start Here]]
2. Open [[Current Cycle Dashboard]]
3. Create the Bases from [[Bases Setup]]
4. Walk through [[Testing Scenarios]]

The vault is intentionally small, readable, and editable by hand.
