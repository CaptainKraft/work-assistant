Release notes should follow the formatting from the most recent version headings.

Each section will have up to 4 headings in this order:
- New Additions
- Improvements
- Changes
- Fixes

If there are not bullets that fit under a heading, then the heading may be omitted.

Your job will be to review and format all release note bullets for the latest heading in each markdown file in this directory.

While you are reviewing, correct any spelling or grammar mistakes, make small changes for clarity, and ensure consistent formatting.

Bullets should not end with periods.

There should be no double quotation marks; replace any that are found with single quotes.
